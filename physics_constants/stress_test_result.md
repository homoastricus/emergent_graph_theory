# Стресс-тест формул эмерджентных констант Единой Теории Информации

## Аннотация

Представлены результаты полного стресс-теста Единой Теории Информации (ЕТИ), включающего прямое предсказание 81 физической константы при фиксированном значении фундаментального параметра $N_0$, анализ ошибок по категориям и процедуру Leave-One-Out (LOO) кросс-валидации. Продемонстрировано, что теория без единого подгоночного параметра предсказывает 80 из 81 констант с ошибкой менее $1\%$, причём 63 из них — с ошибкой менее $0.5\%$. Процедура LOO подтверждает устойчивость предсказаний: при исключении любой константы из набора и перевычислении $N$ ошибка предсказания исключённой величины не превышает $1.05\%$.

## 5. Процедура Leave-One-Out (LOO)

### 5.1 Методология

Для проверки устойчивости предсказаний применяется процедура Leave-One-Out:

1. Из полного набора констант исключается одна ($X_i$).
2. По оставшимся константам вычисляется оптимальное значение $N_{\text{fit}}^{(i)}$ путём минимизации суммарной логарифмической ошибки.
3. С использованием $N_{\text{fit}}^{(i)}$ вычисляется предсказание для исключённой константы $X_i^{\text{pred}}$.
4. Сравнивается $X_i^{\text{pred}}$ с экспериментальным значением $X_i^{\text{exp}}$.

Параметры теста:

|:---------|:---------|

| $\ln N_0$ | $280.044221$ |

2. **Устойчивость (LOO):** При исключении любой константы из набора и перевычислении $N$ значение $N_{\text{fit}}$ изменяется не более чем на $0.25\%$ относительно $N_0$, а ошибка предсказания исключённой константы не превышает $1.05\%$ для 80 из 81 случаев. Единственная константа с ошибкой $>1\%$ ($\Sigma^-$, $1.05\%$) остаётся в пределах экспериментальной неопределённости.

3. **Категории с наилучшим согласием:** Квантовые константы ($0.023\%$) и безразмерные константы ($0.011\%$) предсказываются с наибольшей точностью, что отражает фундаментальный статус этих величин в теории.

4. **Сходимость:** Оптимальное значение $N_{\text{opt}} = 4.194965 \times 10^{121}$ отличается от теоретического $N_0 = 4.1847 \times 10^{121}$ на $0.25\%$, что соответствует порядку NNLO-поправок ($\sim 1/\ln^2 N$).
